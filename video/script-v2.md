# Сценарий видео №2 «Core» (20 секунд)

Формат: вертикальное 1080×1920, MP4 (H.264), без звука, 30 к/с. Закадрового текста нет. Гипотеза: короткий ролик с крупным крючком и живым демо удерживает зрителя дольше, чем первый (60 с, среднее время просмотра 8,3 с, досмотры 1,12%).

Подписи — системный шрифт, 68–150 px, не больше 6 слов на кадре, в верхней части экрана (нижнюю часть закрывает интерфейс TikTok).

| Время | Кадр | Подпись |
|---|---|---|
| 0:00–0:03 | Тёмный фон, без интерфейса. Текст появляется и плавно увеличивается (появление 0,5 с, рост на 20% за 3 с) | «Язык для детей. Без кода.» |
| 0:03–0:08 | Интерфейс крупно (масштаб ×1,5). Блоки мышью встают на место: две переменные, «повторить 10 раз», два «изменить», «показать» | «Собираем сумму из блоков» |
| 0:08–0:12 | Результат запуска крупно по центру, всплывающая анимация | «55» / «Работает!» |
| 0:12–0:18 | Мини-шутер на весь экран, запуск, живой бой: синие против красных, меняется счёт | «Игра из тех же блоков» |
| 0:18–0:20 | Финальный экран с адресом демо | «Попробуй сам: ссылка в профиле» / gipotenuzsa.github.io/core |

## Как снято

- Пять сцен записаны отдельно через Playwright (установлен вне проекта) в окне 1080×1920 и склеены `ffmpeg`.
- Сцена 2 — настоящая запись работы редактора: мышью перетаскиваются блоки, сборка идёт в реальном времени (около 5 секунд), без ускорения. Число «55» в сцене 3 взято из реального вывода программы.
- Сцена 4 — настоящая игра из блоков; управление клавишами эмулируется.
- Заставка и финал — простые HTML-анимации (появление и лёгкое увеличение), шрифт системный.
- Код проекта для съёмки не менялся.
