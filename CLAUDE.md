# Core — правила проекта

Core — учебный мини-язык с блочным редактором на русском языке. Всё написано с нуля: без npm, фреймворков, CDN и сборки. Запуск — двойным кликом по `index.html` (протокол `file://`).

## Правила

1. **Ядро не знает про игры.** Файлы `src/core/*` и `src/editor/blocks-core.js` не упоминают холст, клавиши, пули и т. п. Всё игровое живёт в `src/world/*` и подключается к ядру только как набор встроенных функций `{ имя: { arity, fn } }`. Это проверяет тест `tests/cases/06-blocks.js`.
2. **Один модуль на файл.** Каждый файл — один самодостаточный модуль в виде IIFE, который кладёт свой результат в глобальный объект `Core` (`Core.AST`, `Core.Interpreter`, `Core.World`…). Только обычные скрипты, никаких ES-модулей и `import`/`export`: иначе не заработает с `file://`. Порядок подключения — в `index.html` и `tests/run.js`.
3. **Каждый новый блок сопровождается тестом.** Новый узел AST — тест в `tests/cases/` (вывод, ошибка или текст программы). Новая встроенная функция «Мира» — тест в `05-world.js`; блок в палитре должен иметь описание в `Core.Blocks` (это проверяет `06-blocks.js`).
4. **Блоки и текст — два представления одной программы.** Единственный источник правды — дерево AST. Редактор строит дерево, `Core.codegen` показывает текст (парсера текста пока нет).
5. **Не добавлять зависимости** без разрешения владельца проекта.
6. Все подписи, сообщения об ошибках и документация — на русском.
7. Если этап не получается — не переписывать всё заново, а описать проблему и исправить только нужное.

## Структура

```
index.html            страница редактора
css/style.css         тёмная тема, один акцентный цвет
src/core/             ядро: ast.js, interpreter.js, codegen.js
src/world/            расширение «Мир»: world.js (рантайм), blocks.js (блоки редактора)
src/editor/           spec.js (реестр блоков), blocks-core.js, render.js, editor.js (перетаскивание)
src/demos/            примеры: sum.js, shooter.js
src/app.js            кнопки, панели вывода, запуск
tests/run.js          запуск тестов: node tests/run.js
tests/cases/*.js      случаи: { name, program, output | error | code } или { name, run() }
```

## Команды

```
node tests/run.js     все тесты (нужен только Node.js)
```

## Как добавить блок

1. Узел в `Core.AST` (конструктор) и ветка в `Interpreter.execNode` / `ev`.
2. Строка в `Core.codegen`.
3. Описание в `Core.Blocks.register` (или `registerBuiltin` для функции «Мира»).
4. Тест в `tests/cases/`.
